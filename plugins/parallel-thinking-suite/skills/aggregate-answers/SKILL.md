# 聚合答案

仅在用户要求聚合并行运行时使用；默认读取当前项目的 `latest`，或用户指定的
runId。执行 CLI 前按[运行前置条件](../../docs/skill-runtime.md)核实 Node 和构建。

1. 以本目录向上两级为插件根，运行：
   `node <插件根>/dist/cli.mjs context --run <latest或runId> --project-root <当前项目根>`。
2. 根据归档的公开答案，在当前对话汇总各 Agent 判断、共识、关键分歧及原因、
   证据与假设边界、遗漏、风险、建议和仍需用户决定的问题；注明来源 Agent。
3. 只有用户明确要求专用聚合 Agent，才运行同一 CLI 的
   `aggregate --run <latest或runId> --project-root <当前项目根>`。
   失败时保留原始结果，回到当前对话汇总，不伪造聚合成功。

返回运行编号和已知执行器。失败或未归档 Agent 没有可假定的完整答案；模型与
用量只使用宿主实际报告的数据，未知保持未知。不得要求或展示隐藏思维链。
